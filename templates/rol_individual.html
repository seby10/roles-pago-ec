¿Cómo se calculó este rol?
  1. Valor de la hora {{ d.sueldo|money }} ÷ 240 h = {{ vh|money }} 240 h = 40 h semanales × 4 semanas (mes comercial de 30 días).
  2. Total gravado {{ d.sueldo_ganado|cifra }} + {{ (d.v_h50 + d.v_h100)|cifra }} + {{ d.comisiones|cifra }} = {{ d.total_gravado|money }} Sueldo ganado + horas extras + comisiones. Es la base del IESS, del IR y de las provisiones.
  3. Aporte personal IESS {{ d.total_gravado|cifra }} × {{ P.iess_personal }} = {{ d.iess_personal|money }}
  4. Base imponible anual del IR ({{ d.total_gravado|cifra }} − {{ d.iess_personal|cifra }}) × 12 = {{ d.base_ir_anual|money }} Proyección del mes a 12 meses. El aporte al IESS es la única deducción de la base.
  5. Impuesto causado (tabla SRI 2026) {{ d.ir_impuesto_fb|cifra }} + {{ '%g'|format(d.ir_pct) }}% × ({{ d.base_ir_anual|cifra }} − {{ d.ir_tramo_desde|cifra }}) = {{ d.ir_causado|money }} Fracción básica del tramo + porcentaje sobre el excedente. Hasta $ 12.208 no se paga.
  6. Rebaja por gastos personales {% if d.gastos_personales %} 18% × menor({{ d.gastos_personales|cifra }} ; tope {{ d.tope_gp|cifra }}) = {{ d.rebaja_gp|money }} Tope = {% if d.catastrofica %}{{ P.canastas_cat }} canastas × $ {{ P.canasta }} por enfermedad catastrófica{% else %}{{ P.canastas[[d.cargas, 5]|min] }} canastas × $ {{ P.canasta }} por {{ d.cargas }} carga{{ '' if d.cargas == 1 else 's' }} familiar{{ '' if d.cargas == 1 else 'es' }}{% endif %}. Resta del impuesto, no de la base. {% else %} Sin proyección de gastos personales → {{ 0|money }} Si el trabajador entrega su formulario de gastos personales, el impuesto baja hasta 18% de lo proyectado. {% endif %}
  7. Retención mensual del IR ({{ d.ir_causado|cifra }} − {{ d.rebaja_gp|cifra }}) ÷ 12 = {{ d.ir|money }}
  8. Neto a recibir {{ d.total_ingresos|cifra }} − {{ d.total_descuentos|cifra }} = {{ d.neto|money }} {% if d.total_no_gravado %}Incluye {{ d.total_no_gravado|money }} no gravados (beneficios mensualizados): no aportan al IESS ni pagan IR.{% endif %}
  9. Costo para la empresa {{ d.total_gravado|cifra }} + {{ d.total_provisiones|cifra }} = {{ d.costo_total|money }} Gravado + provisiones + aportes patronales. Mensualizar un beneficio no cambia el costo, solo cuándo se paga.
